راهنمای API پنل MMD (Marzban)

این سند برای اتصال مستقل به پنل MMD با حساب کاربری اختصاصی خودتان است. هیچ رمز، توکن داخلی یا اطلاعات PhantomHubs در این فایل وجود ندارد.

Base URL: https://mmd-panel.serendpiti.ir
مسیر /dashboard/ فقط رابط وب است؛ در درخواست های API از آدرس پایه بالا استفاده کنید.
برای مشاهده قرارداد دقیق نسخه همان پنل، پس از ورود به /docs یا /openapi.json مراجعه کنید.

1. دریافت توکن دسترسی

نام کاربری و رمز حساب خودتان را فقط در بک اند نگه دارید. هر بار که توکن منقضی شد، دوباره آن را دریافت کنید.

curl -X POST 'https://mmd-panel.serendpiti.ir/api/admin/token' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data-urlencode 'username=YOUR_PANEL_USERNAME' \
  --data-urlencode 'password=YOUR_PANEL_PASSWORD'

خروجی شامل access_token است. در درخواست های بعدی این هدر را بفرستید:

Authorization: Bearer YOUR_ACCESS_TOKEN

2. دریافت اینباندها

قبل از ساخت کاربر، اینباندهای واقعی همان حساب/پنل را بخوانید و فقط از protocol و tag بازگشتی استفاده کنید.

curl 'https://mmd-panel.serendpiti.ir/api/inbounds' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'

نمونه بخشی از پاسخ:

{
  "vless": [
    { "tag": "YOUR_INBOUND_TAG", "port": 443, "network": "ws", "tls": "tls" }
  ]
}

3. ساخت کاربر

حجم بر حسب بایت است: GB * 1024 * 1024 * 1024. برای حجم نامحدود مقدار data_limit را 0 قرار دهید. زمان expire بر حسب Unix timestamp و UTC است؛ 0 یعنی بدون تاریخ انقضا.

curl -X POST 'https://mmd-panel.serendpiti.ir/api/user' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  --data '{
    "username": "ExampleUser_1",
    "status": "active",
    "data_limit": 10737418240,
    "data_limit_reset_strategy": "no_reset",
    "expire": 0,
    "on_hold_expire_duration": null,
    "proxies": { "vless": {} },
    "inbounds": { "vless": ["YOUR_INBOUND_TAG"] }
  }'

از پاسخ، فیلد subscription_url را برای کاربر ارسال کنید. اگر این مقدار نسبی بود، آن را به آدرس پایه بچسبانید:

const absoluteSubscriptionUrl = new URL(response.subscription_url,
  'https://mmd-panel.serendpiti.ir').toString();

حالت های زمان

حالتفیلدهای لازم
فعال تاریخ دارstatus: "active" و expire: UNIX_TIMESTAMP
فعال بدون تاریخstatus: "active" و expire: 0
On holdstatus: "on_hold"، expire: 0 و on_hold_expire_duration: SECONDS
غیرفعالstatus: "disabled"

نمونه Python

import httpx

BASE_URL = "https://mmd-panel.serendpiti.ir"
USERNAME = "YOUR_PANEL_USERNAME"
PASSWORD = "YOUR_PANEL_PASSWORD"

with httpx.Client(base_url=BASE_URL, timeout=30) as client:
    login = client.post("/api/admin/token", data={
        "username": USERNAME,
        "password": PASSWORD,
    })
    login.raise_for_status()
    token = login.json()["access_token"]
    headers = {"Authorization": f"Bearer {token}"}

    inbounds = client.get("/api/inbounds", headers=headers)
    inbounds.raise_for_status()
    print(inbounds.json())

    payload = {
        "username": "ExampleUser_1",
        "status": "active",
        "data_limit": 10 * 1024 ** 3,
        "data_limit_reset_strategy": "no_reset",
        "expire": 0,
        "on_hold_expire_duration": None,
        "proxies": {"vless": {}},
        "inbounds": {"vless": ["YOUR_INBOUND_TAG"]},
    }
    created = client.post("/api/user", headers=headers, json=payload)
    created.raise_for_status()
    user = created.json()
    print(httpx.URL(BASE_URL).join(user["subscription_url"]))

نکات سازگاری و امنیت

  • برای HWID یا محدودیت دستگاه، فیلد یکسان و تضمین شده ای در API استاندارد Marzban وجود ندارد. ابتدا قرارداد /docs همان پنل را بررسی کنید؛ افزونه های پنل ممکن است API متفاوتی داشته باشند.
  • در صورت خطای 401 یا 403، اطلاعات ورود یا سطح دسترسی API را بررسی کنید. خطای 422 معمولاً به معنی نامعتبر بودن فیلدها، پروتکل یا تگ اینباند است.
  • رمز پنل، access token و هر توکن همگام سازی داخلی را هرگز در فرانت اند، ربات عمومی، GitHub یا پیام های عمومی قرار ندهید.
  • اگر لازم است لینک اشتراک روی دامنه اختصاصی نمایش داده شود، این کار باید توسط سرویس اشتراک مستقل همان مجموعه انجام شود؛ API مرزبان فقط لینک اصلی پنل را برمی گرداند.
